## Rollback

Back up the published 2.2.0 assets before replacing the release listing. The new SQLite table is additive. Audio renaming preserves track IDs; backups preserve audio and metadata, not authentication. Android normally prevents version-code downgrades, so do not uninstall to roll back: preserve the library and ship a corrected higher-version update if needed. A startup crash, library corruption, or reproducible download regression should stop distribution pending a corrected update.
