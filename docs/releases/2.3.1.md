# Sonkip 2.3.1 — choose your music folder

## What changed

- Android and desktop now offer **Library → Music folder**.
- Choosing a folder copies the existing library and automatically copies future downloads there.
- Shared files keep readable artist/title names and their original audio format, so other compatible music players can scan and play them.
- Sonkip retains its internal library copy. Changing folders or choosing **Stop copying** never deletes earlier external copies.
- Copy failures are reported without losing the song stored inside Sonkip.

## Android verification

The update was installed over an existing library on a Xiaomi/Redmi Android 15 phone. The system folder picker granted access, Sonkip copied all 86 saved songs to shared Music storage, and three copied files (WebM and M4A) completed full FFmpeg decoding with exit code 0.

## Limits

External copies use additional storage. Sonkip preserves the downloaded source format rather than converting everything to MP3, so the other music player must support WebM/Opus, M4A/AAC, or the file's original format. Removable or cloud-backed folders may become unavailable; reconnect them and use **Copy / retry**.
