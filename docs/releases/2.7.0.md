# Sonkip 2.7.0 — the website's style, made for your phone

Sonkip's Android interface now uses the same visual language as the website: square controls, fine borders, paper and ink surfaces, orange actions, and acid-yellow playback highlights.

## What's changed

- Reworked Find, Library, Downloads, and playlist review for comfortable mobile use.
- Replaced rounded buttons, cards, and dialogs with clean, square surfaces.
- Applied Manrope and DM Mono throughout app dialogs and actions.
- Added an expandable player with seeking, previous/next, queue, repeat, and sleep timer controls.
- Made playlist song selection searchable, with a visible selection count.
- Fixed the Music folder menu, stray null metadata, lingering success notices, disabled Save states, and oldest-first download history.

## Install

Download **Sonkip-2.7.0.apk** below and install it over your existing app. The signing certificate is unchanged, so your library and playlists are kept. Android 7.0 or later on ARM/ARM64 is supported.

This is a release build with debugging disabled. It retains the existing signing identity for upgrade compatibility.
