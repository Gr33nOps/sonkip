# Sonkip 2.6.1 — setup and safer downloads

This update makes the initial settings clearer and avoids more duplicate or mismatched downloads.

## What's new

- First launch asks for audio format, song details and artwork, and an optional Music folder on Android and desktop.
- Android checks the phone's indexed audio library when audio access is granted. Playlist songs with matching title, artist, and duration are skipped.
- Songs already saved in Sonkip are reused even when a different output format is selected.
- Android now uses the same Manrope and DM Mono fonts as the website.
- Search favors artist releases over lyric videos, reuploads, and making-of clips. Playlist imports do not auto-match lyrics-only uploads for standard recordings.
- If an Android upload has no AAC/M4A stream, Sonkip saves its available original audio and shows the actual format in Downloads.
- Old failed download entries are removed when the song is already saved.

## Before installing

Install the APK over your existing Sonkip app. Do not uninstall it first, because uninstalling removes its private library. Export a backup before any destructive library changes.

Android's phone-library duplicate check needs audio access and reliable title, artist, and duration tags. An untagged or differently named file may not be recognized. Some sources can still be unavailable or restricted by their provider.
