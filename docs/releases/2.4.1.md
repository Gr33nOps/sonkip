# Sonkip 2.4.1 — choose your audio format

New downloads can now keep the source audio or use a selected output format. Desktop supports Original, MP3, M4A, Opus, and FLAC. Android supports Original, M4A/AAC, and Opus/WebM.

The chosen format is remembered and applies to individual songs, imported playlists, retries, and resumed downloads. Existing library files are not converted or replaced.

On Android, Sonkip downloads an existing compatible stream without transcoding. If AAC is available only inside an MP4 stream, Android extracts the audio track locally into an audio-only M4A file. No cloud conversion or account is involved.
