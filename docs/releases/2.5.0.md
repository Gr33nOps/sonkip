# Sonkip 2.5.0 — music details & artwork

New downloads can now carry their song information with them. Sonkip embeds standard title, artist, album, track number, year, genre, and cover-art tags whenever the matched source provides those details.

The **Music details & artwork** option is enabled by default and remembered on Android and desktop. Turn it off before downloading if you want an untagged file. The setting applies to individual songs, imported playlists, retries, and resumed downloads.

M4A/AAC is recommended on Android for broad music-player compatibility. MP3, FLAC, and Opus tagging is also supported on desktop. Original downloads receive tags only when their existing container supports them; WebM files remain playable but do not support this embedded artwork path.

Artwork and tags are written locally before Sonkip copies the file to the selected Music folder. Android then notifies the folder provider so Gramophone and other music players can refresh the song. Missing artwork or malformed source metadata never causes a playable download to fail.
