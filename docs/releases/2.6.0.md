# Sonkip 2.6.0 — better albums, safer playlists

This release makes album imports easier to trust and downloaded music easier for other players to organize.

## What's new

- Playlist and album imports now show a complete review list before any download starts. Tracks are selected by default, with Select all, Deselect all, and Save selected controls.
- Search ranking favors exact title/artist matches and official artist uploads while lowering live, cover, remix, remaster, and unrelated versions.
- Downloads carry cleaner title, artist, album artist, album, track number, year, genre, release identity, and artwork metadata when the source provides it.
- Tracks from the same release are recognized across different YouTube uploads, reducing duplicate downloads.
- Android now shows cover art and album details throughout search, review, downloads, and the library.
- The website has clearer keyboard focus, stronger contrast, correct control semantics, live status announcements, larger touch targets, safer dialog scrolling, and more stable image layout.

## Before installing

Install this APK over the existing Sonkip app. Do not uninstall first: uninstalling removes the app-private library. Export a backup or copy important files to a shared Music folder before making any destructive library changes.

Public sources can still be unavailable, region-restricted, rate-limited, or changed by their provider. Review matched tracks before saving them. Sonkip does not bypass DRM, paywalls, or provider permissions.
