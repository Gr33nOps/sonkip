# Sonkip 2.7.1 — covers, complete playlists, and connected libraries

This release fixes missing cover art, incomplete Spotify playlist imports, incorrect release details, and deletion sync between Saved and the selected Music folder.

## What's changed

- Read all pages of public Spotify playlists, including those with more than 100 tracks. Report repeated recordings and unmatched tracks separately; page failures no longer produce a silently incomplete import.
- Prefer artist-delivered YouTube Music recordings and reject lyric uploads, unrelated performers, and unwanted remixes or live versions when matching playlists.
- Preserve album, album artist, release type, release date, and album track number. Missing release information is no longer automatically treated as a single.
- Embed covers in Android M4A and Original/Opus audio using compatible containers without re-encoding the audio. Saved Library covers load from local files, including offline.
- Add **Library → Repair details & covers** for older downloads. Repair reuses their audio and updates connected Music-folder copies.
- Keep Saved and the selected Music folder connected: deleting a linked song from either side removes its other copy on the next sync. An unavailable folder does not count as deletion. Independent exports and disconnected folders are kept.

## Install

Download **Sonkip-2.7.1.apk** and install it over your existing app to preserve your songs and playlists. Android 7.0+ on ARM/ARM64 is supported. Debugging is disabled; the signing identity is unchanged.

Keep **Details On** enabled for tagged downloads. To repair older files, use **Library → Repair details & covers**. Other music players may need to refresh their library after the Music folder syncs.

## Verification and limits

- 117 Python tests, 59 Android unit tests, and 25 JavaScript tests passed. Android lint and release assembly passed.
- Tested on Android 15: repaired covers and album tags in all 88 existing songs, verified visible Library covers and playback, and tested deletion in both directions against the actual Music-folder provider.
- A 250-entry Spotify playlist preview returned 244 unique official matches, four repeated recordings, and two unmatched tracks. Two representative tracks were downloaded and checked for embedded covers and release tags. The entire playlist audio batch was not downloaded again.
- Unavailable or restricted official recordings can remain unmatched. Review playlist matches before saving; matching does not guarantee an identical recording.
