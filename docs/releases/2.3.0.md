# Sonkip 2.3.0 — recovery and library tools

Download the Android APK below, or use the [desktop setup](https://github.com/Gr33nOps/sonkip#quick-start) on Windows, macOS, or Linux.

## Changes

- Downloads survive app restarts in the queue. Reopening Sonkip resumes interrupted work, using retained partial files where possible.
- Temporary connection failures retry up to three extraction attempts. Cancel individual jobs or retry failed jobs without restarting cancelled ones.
- Repeated requests reuse queued or saved songs. Android search results offer **Play saved** for an existing song.
- Downloaded filenames no longer repeat an artist already included in the title. Existing repeated-artist filenames are migrated without changing library IDs.
- Search/sort the library on desktop and Android.
- Export and restore music backups; Android backups include custom playlists. Authentication files are excluded.
- Android: repeat one/all, edit upcoming songs, and set a sleep timer.
- Playlist matching prefers verified artist channels when title, artist, and duration agree. Uncertain matches wait for your choice.
- Partial download fragments cannot be mistaken for completed songs.

## Install safely

Install updates over the existing app. Do not uninstall unless you have exported a backup. Keep the original APK signing identity for future updates.

## Limits

Private, unavailable, region-restricted, sign-in-only, and DRM-protected media are not guaranteed to download. Spotify and SoundCloud provide metadata; audio comes from YouTube matches. Public Spotify embeds may show only part of a playlist.

Android may stop work after force-stop, a restart, or manufacturer cleanup. Interrupted downloads recover after reopening; playback does not restart automatically. The active player queue is not a persistent listening session.
