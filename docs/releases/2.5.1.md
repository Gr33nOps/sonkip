# Sonkip 2.5.1 — faster library cleanup

This small update makes larger local libraries easier to manage.

## Changes

- Tap **Select songs** in Library to choose songs one by one.
- Use **Select all** to select every song currently visible after searching or sorting.
- **Delete selected** removes the chosen songs and clears their completed entries from Downloads.
- Compatible **M4A/AAC** is now the default for fresh installs. Sonkip keeps the format already chosen by an existing user.

Files previously exported or copied into another music folder are not deleted.

## Verification

- 71 Python tests passed.
- 19 browser behavior tests passed.
- 40 Android unit tests passed, with Android lint clean.
- The APK is signed and supports Android 7+ on ARM and ARM64.

Install this APK over your current Sonkip installation so the existing app-private library remains available.
