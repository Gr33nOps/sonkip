# Sonkip 2.2.0

Find it. Save it. Play it.

An open-source music library on your own device. No Sonkip account, analytics, or cloud library.

## Download

- **Android:** install `Sonkip-2.2.0.apk` from the assets below. Android 7 or newer, ARM or ARM64.
- **Windows, macOS, Linux:** follow the [one-command setup](https://github.com/Gr33nOps/sonkip#quick-start).
- **Source code:** the ZIP and tar.gz below contain the code, not a desktop executable.

Updating Android? Install over the existing app. **Do not uninstall first**—uninstalling removes the app-private music library. Export files you want to keep separately.

## In this release

- Native Android Find, Downloads, and Library screens in Sonkip's cream, orange, black, and lime theme.
- Play all in download order, Shuffle, automatic next-song playback, and previous/next controls.
- Local playlists: choose songs, add from Library, rename, delete, play in order, or shuffle.
- Background playback and downloads, with notification and lock-screen media controls.
- Download notifications with transfer percentage, saved/failed counts, and expanded transfer-speed details.
- Public Spotify playlist/album and SoundCloud set metadata matched to YouTube audio.
- Readable artist/title filenames on desktop and Android, including migration of older ID-named library files.

## Verification and limitations

The source commit passed GitHub Actions, and 67 automated tests passed locally. The signed APK was built locally from that source; its SHA-256 is included below. The latest physical-phone checks for playlist controls, notifications, and screen-off downloads are **not yet complete**. Please report device-specific problems rather than assuming universal compatibility.

Only download content you own or have permission to download. Restricted, unavailable, or DRM-protected media may not work. Spotify public embeds can expose only part of a playlist; YouTube matches may be different uploads or editions.

Force-stopping the app or restarting the phone interrupts unfinished jobs; automatic queue recovery is not supported. Android and manufacturer battery rules may limit background work. Android 15 limits background data-sync services to six hours per day.
